# SpinScript for VS Code

VS Code extension for `.spin` files (SpinScript language support).

Right now this is just a TypeScript hello-world skeleton — language
features (syntax highlighting, diagnostics, etc.) will be added on top
of this.

## Development

```bash
npm install
npm run compile
```

Then press `F5` in VS Code (with this folder open) to launch an
Extension Development Host, and run the **SpinScript: Hello World**
command from the command palette (`Ctrl+Shift+P`).
